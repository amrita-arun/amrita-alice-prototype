# LOT levels. 6x6 grid, x = column (0 left), y = row (0 bottom).
#
# level <name>
# exit  <L|R|T|B> <index>      the REAL exit (drawn as a slightly thicker wall)
# notch <L|R|T|B> <index>      optional fake exit (a painted gap that is a wall)
# car   <x> <y> <len> <H|V> <color> [target] [fuelN] [left|right|up|down]
#        x,y is the bottom-left cell. color: red blue teal yellow purple orange green pink gray
#        target = the car that must leave (it breathes)
#        fuelN  = the car can only be dragged N more times (pips on its roof); no fuel token = unlimited
#        left/right/up/down = headlight; the car can only drive that way
#        cars that share a color (and are not the target) always move together
# end
#
# Check solvability after editing:  python3 Tools/solve_levels.py
